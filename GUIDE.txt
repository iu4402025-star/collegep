PDF STUDY & QUESTION PAPER GENERATOR
======================================

FILES
-----
1. app.py
   Main Streamlit application.

2. requirements.txt
   Python packages required by the application.

3. GUIDE.txt
   Installation, GitHub, and Streamlit deployment instructions.


==================================================
PART 1 — INSTALL PYTHON
==================================================

Download and install Python 3.11 or newer from:

https://www.python.org/downloads/

During Windows installation, select:

Add Python to PATH


==================================================
PART 2 — CREATE PROJECT FOLDER
==================================================

Create a folder:

pdf-study-question-generator

Put these files inside it:

pdf-study-question-generator/
    app.py
    requirements.txt
    GUIDE.txt


==================================================
PART 3 — CREATE VIRTUAL ENVIRONMENT
==================================================

Open Command Prompt inside the project folder.

Run:

python -m venv .venv

Windows:

.venv\Scripts\activate

macOS/Linux:

source .venv/bin/activate


==================================================
PART 4 — INSTALL REQUIREMENTS
==================================================

Run:

pip install -r requirements.txt


==================================================
PART 5 — RUN THE APPLICATION
==================================================

Run:

streamlit run app.py

The application normally opens at:

http://localhost:8501


==================================================
PART 6 — TEST THE APPLICATION
==================================================

1. Upload a Computer Science textbook PDF.
2. Wait for the PDF to be processed.
3. Select a chapter/unit.
4. Select MCQs, Short Questions, or Long Questions.
5. Select the number of questions.
6. Enter your OpenAI API key if you want AI generation.
7. Click Generate Questions.
8. Open the Question Paper tab.
9. Select total marks and number of questions.
10. Generate the complete paper.
11. Download the paper as question_paper.txt.

==================================================
PART 9 — OPENAI API KEY
==================================================

The application can accept an OpenAI API key through the sidebar.

For a deployed application, a safer approach is to use Streamlit Secrets.

In Streamlit deployment settings, add:

OPENAI_API_KEY = "your-api-key"

For production, modify app.py to read:

api_key = st.secrets["OPENAI_API_KEY"]

instead of asking the user to type the key.

Never commit an API key to GitHub.


==================================================
PART 10 — IMPORTANT PDF LIMITATION
==================================================

The application extracts selectable text from PDF files.

If the textbook is a scanned PDF containing only images, pypdf may extract little or no text.

For scanned books, add an OCR stage in a future version.
